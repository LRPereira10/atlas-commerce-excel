# Atlas Commerce — Análise de Vendas e Performance Comercial

Projeto de análise de dados desenvolvido em Excel para simular o cenário de uma empresa de comércio de produtos eletrônicos.

## 📊 Sobre o projeto

O Atlas Commerce é um projeto de análise de dados desenvolvido para simular o cenário de uma empresa de comércio de produtos eletrônicos.

A partir de uma base de dados fictícia contendo informações de vendas, produtos, clientes e estoque, o projeto busca transformar dados brutos em indicadores e informações relevantes para apoiar a tomada de decisão.

O projeto foi desenvolvido como parte da construção de um portfólio na área de Dados, com foco na aplicação prática de conceitos de análise e visualização de dados utilizando o Microsoft Excel.
